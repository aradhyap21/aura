[1] (Heading 1) 1. Application Architecture
[2] (Heading 2) 1.1 Selected Architecture: Hybrid (Microservices + Event-Driven)
[3] (Normal) TASA follows a hybrid architecture combining Microservices and Event-Driven Architecture to ensure scalability, modularity, and efficient processing.

• Microservices separate core functionalities (upload, extraction, scoring, feedback)
• Event-driven approach enables asynchronous execution of pipeline stages

Benefits:
• Scalable system design
• Loose coupling between components
• Efficient AI pipeline execution
[4] (Heading 2) 1.2 System Overview
[5] (Normal) TASA is an AI-based grading system that processes student submissions through the following stages:

• Upload submission
• Text extraction
• Evidence extraction
• Scoring
• Review
• Feedback generation
• Result storage and display
